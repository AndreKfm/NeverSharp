## Goal

Port from checker.ts:

- inference contexts and infos (`createInferenceContext`, `InferenceFlags`, `InferencePriority`, mappers, `cloneInferenceContext`), `inferTypes` with all its cases (`inferFromTypes`, union/intersection matching, `inferToMultipleTypes`, type references with variance, `inferFromObjectTypes`, properties, signatures, index signatures, tuples and variadic elements, mapped types and reverse mapped types (`inferTypeForHomomorphicMappedType`, `createReverseMappedType`), template literal types, conditional types, `infer` type parameters), `getInferredType(s)` with widening, defaults, constraints, `getCovariantInference`/contravariant candidates, `isTypeParameterAtTopLevel`;
- inference in calls: `inferTypeArguments` (context-sensitive arguments in two passes, `checkMode` `Inferential`/`SkipContextSensitive`, return-type inference from the contextual type, `instantiateSignatureInContextOf`, `getSignatureInstantiation`), inference for JSX/tagged templates/decorators where C5 calls the seam, `applyToReturnTypes` with type predicates (C7's stub);
- inference of `infer` type parameters in conditional types (C3's uninferred mapper) and in conditional-to-conditional relations (C4's stub);
- generic function arguments (`getReturnTypeOfSingleNonGenericCallSignature`, higher-order generic inference `instantiateSignatureInContextOf` with `inferenceContext.returnMapper`), `isContextSensitive`-driven deferral.
