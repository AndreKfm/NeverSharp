## Goal

The machinery every transformer module (D2–D5) runs on. Its tests come through D2, so D1 and the start of D2 may be done together (see "Target").

**1. Transformation pipeline** (`transformer.ts`):
- `getTransformers` / `getScriptTransformers` / `getDeclarationTransformers` for the default options, in tsc's order (D0's emitter currently passes empty lists);
- `transformNodes` with the `TransformationContext`:
  - lexical environment: `startLexicalEnvironment`, `endLexicalEnvironment`, `hoistVariableDeclaration`, `hoistFunctionDeclaration`, `addInitializationStatement`, the block-scope variants;
  - `requestEmitHelper` / `readEmitHelpers`;
  - `enableSubstitution` / `enableEmitNotification`;
  - the chained `onSubstituteNode` / `onEmitNode` hooks the printer calls;
- `isEmitNotificationEnabled` / `isSubstitutionEnabled`;
- the transformed-tree disposal rules;
- node visitors (`visitor.ts`: `visitNode`, `visitNodes`, `visitEachChild`, `visitLexicalEnvironment`, `visitParameterList`, `visitFunctionBody`, `visitIterationBody`).

**2. Emit helpers** (`factory/emitHelpers.ts`) for the helpers the default-option transformers request:
- decorators: `__esDecorate`, `__runInitializers`, `__setFunctionName`, `__propKey`;
- `__addDisposableResource` / `__disposeResources`;
- `__classPrivateField*` and `__rewriteRelativeImportExtension` where reached.

Include the printer's helper emission (`emitHelpers`, `noEmitHelpers`, unscoped helpers before the prologue) and the generated-name machinery (`createUniqueName`, `getGeneratedNameForNode`, temp variables, `makeUniqueName`, `isUniqueName`) in the printer. These remove D0's `NotSupportedException` paths.

**3. Emit resolver** (`createResolver` in `checker.ts`, line 51,380 ff.). Port what the default-option transformers and declaration emit query, in tsc's semantics:
- `isReferencedAliasDeclaration`, `isValueAliasDeclaration`, `isTopLevelValueImportEqualsWithEntityName`;
- `getReferencedExportContainer`, `getReferencedImportDeclaration`, `getReferencedDeclarationWithCollidingName`, `isDeclarationWithCollidingName`;
- `getConstantValue`, `getEnumMemberValue`;
- `getTypeReferenceSerializationKind` (only if reached);
- `isArgumentsLocalBinding`, `getNodeCheckFlags`;
- `requiresAddingImplicitUndefined`, `isLiteralConstDeclaration`, `isImplementationOfOverload`;
- `isDeclarationVisible`, `isEntityNameVisible`, `collectLinkedAliases`;
- `createTypeOfDeclaration`, `createReturnTypeOfSignatureDeclaration`, `createTypeOfExpression`, `createLiteralConstValue`;
- `getJsxFactoryEntity` (only if reached).

The declaration-emit entries may stay stubs for D5 if their tests only come there; say which. The resolver comes from the checker that checked the file, as in tsc (and typescript-go's `GetEmitResolver`). Nothing writes into a file's store.

**4. Synthesized nodes:**
- original-node links (`getOriginalNode`, `setOriginalNode`);
- `setTextRange` on synthesized nodes;
- emit flags and comments on synthesized nodes (`setCommentRange`, `setSourceMapRange` as a no-op, `addSyntheticLeadingComment`), as far as D2–D5 need;
- extend the factory's arena layout for transformed trees if needed, and record the decision in the layout note.
