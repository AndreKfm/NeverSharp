## Goal

**1. Drivers with an emit mode.** After the same diagnostics as the check mode (semantic and global diagnostics of every program file, as in §17), emit every program file to memory with Gate D's options: Gate C's options plus `declaration: true` and `newLine: lf`, with TypeScript 6.0.3's defaults given explicitly where TypeScript 7's differ.

| Driver | Flags | Emit |
|---|---|---|
| C# (`tools/NeverSharp.ParseDriver`) | `--check --emit [--single] [--checkers N]` | Track O's `Program.Emit` with an in-memory write: checkers as in the check mode (4, file *i* to checker *i* mod 4), each file emitted with its own checker's resolver. |
| Go (`harness/bench/go/parse.go`) | `--check --emit [--single]` | typescript-go 7.0.2's `Program.Emit` with an in-memory `WriteFile`, through its default checker pool of 4. |
| tsrs (`harness/bench/rust/parse-rs`) | `--check --emit [--single]` | tsrs 0.18.0's emit API (`Program::emit` or what 0.18.0 has), with the same explicit options. If 0.18.0 has no usable emit API, stop there and report it; the orchestrator takes it to the author. |

- Every driver prints the output file count, the total output bytes and the diagnostic counts, so that the work done can be compared.
- The emitted text is not written to disk in timed runs. Add a switch that dumps the output files canonically, for goal 3.

**2. `bench.mjs` and `report.mjs`:**
- Add the configurations `cs-o-aot-ws-emit`, `cs-o-aot-ws-emit-single`, `cs-o-aot-srv-emit`, `cs-o-aot-srv-emit-single`, `tsgo7-emit`, `tsgo7-emit-single`, `tsrs-emit` and `tsrs-emit-single`.
- Add the profile `emit` with exactly these configurations. Its binding rows (`PROFILE_RIG_CHECK.emit`) are `tsgo7-emit-single` and `cs-o-aot-ws-emit-single`.
- **Only add.** Existing configurations, profiles and their output must not change. Show that with `bench.mjs --profile check --runs 1 --warmup 0 --dry-run`, or the equivalent listing, before and after.
- The report gets an emit table in the style of the check tables: G against `tsgo7-emit` with interval and verdict per §8, the single and Server GC rows, tsrs, the output bytes and file counts per side, and the diagnostic counts.

**3. Emit equivalence of the repository programs** (not timed, not a gate): `check-equivalence.mjs --emit`, or a sibling script.
- **Programs:** each benchmark repository's file list as one program.
- **tsc 6.0.3 side:** `program.emit()` after the diagnostics, with an in-memory `writeFile`.
- **C# side:** the driver's dump switch, single-threaded.
- **Compare:** output by output (name and text) and the emit diagnostics.
- **Report:** identical or not, the differences grouped by cause, and the total bytes of every side.
- **typescript-go and tsrs:** their file counts and bytes next to them. They are expected to differ (TypeScript 7).
- **Corpus:** also run it on the tuning-check list (`--corpus tuning-check`).

**4. Smoke runs only** (allowed before the tag):
- every new configuration once on one repository with `--runs 1 --warmup 0`, to show it runs and prints its counts;
- the C# emit driver on tuning-check with 4 and with 12 checkers, output identical between the two and with the single-threaded output.

**Target:** drivers, configurations, profile and report ready for the protocol run. Emit equivalence of the five repository programs and tuning-check against tsc 6.0.3, with every difference explained.
