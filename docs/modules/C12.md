## Goal

1. **No crash.** Find the cause of the crash above (delta-debug the file list to the smallest crashing program, reduce it to a minimal repro, compare with tsc on the same program) and port what tsc does; no defensive guards that hide a wrong index. Then run the whole program again: further crashes may hide behind the first; fix each the same way. Parallel and `--single` must both finish.
2. **Equivalence on the tuning program.** `node harness/bench/check-equivalence.mjs --corpus tuning` (tsc 6.0.3 against `cs-o-aot-ws --check --single`; rebuild with `node harness/bench/build-cs.mjs --tracks optimized --runtimes aot-ws` first; the tsc side of this program is slow, cache its output in your scratch and rerun only the C# side while iterating). Target: identical. Each difference by cause; fix causes in the checker (port, do not sort or special-case to fake an order). A difference whose cause lies outside the checker (parser, binder, program layer) is reported, not fixed.
3. **Parallel stability.** After the fixes, `cs-o-aot-ws --check` (4 checkers) on the tuning program 4 times: no crash, the same diagnostic count each time. Remember the rule of b42ecc2: a checker never writes into a store shared with the other checkers (file stores, the program); per-checker state stays in the checker.

Target: the tuning program checks without a crash in both modes, identical with tsc 6.0.3 or with every remaining difference explained; Gate C and the five repository programs unchanged.
