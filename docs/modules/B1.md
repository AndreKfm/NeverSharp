## Goal

Port `binder.ts` of TypeScript 6.0.3 (`external/typescript/src/compiler/binder.ts`, structure may follow typescript-go's `internal/binder/binder.go`) into Track O, as far as symbols are concerned:

- `createBinder` / `bindSourceFile` state, `bind`, `bindChildren`, `bindContainer`, container flags (`getContainerFlags`), `nextContainer` chain, block-scope containers, `locals`;
- `declareSymbol`, `addDeclarationToSymbol`, symbol merging and exclusion flags, `declareSymbolAndAddToSymbolTable`, `declareModuleMember`, `declareClassMember`, `declareSourceFileMember`, `getDeclarationName`, `getDisplayName`, exports/`exportSymbol`/`localSymbol`, `globalExports`, module instance state (`getModuleInstanceState`), the declaration kinds (variables, functions, classes, interfaces, type aliases, enums, modules/namespaces, imports/exports, parameters, properties, methods, accessors, signatures, type parameters, object literals, anonymous symbols such as `__function`, `__object`, `__type`), and the bind diagnostics these paths report (duplicate identifiers and similar);
- the traversal must be complete enough that B2 (flow graph) and B3 (JavaScript special assignments, JSDoc typedefs/callbacks, strict-mode and remaining diagnostics) only add to it: put the flow-graph calls in place as stubs where `binder.ts` makes them, and the JS/JSDoc branches as stubs.

Utilities from `utilities.ts` / `utilitiesPublic.ts` the binder needs are ported into Track O as needed (reuse what Track O already has).
