## Goal

Port, for the default options (module kind ES2022, target ES2025):

**1. `transformers/module/esnextAnd2015.ts`** (439 lines):
- `export {}` for modules whose remaining statements have no import or export (`isExternalModule` with an empty-module marker, `createEmptyExports`);
- `export = ` and `import x = require(...)` as tsc emits them for ES module kinds, including the diagnostics tsc reports through the checker, not the emitter;
- `export * as ns from` rewritten to the import plus export form for this module kind;
- `import.meta`, `createRequire` and the helpers it uses, only where tsc emits them under these options;
- `rewriteRelativeImportExtensions` only if the default options reach it (they should not).
- Also the dispatch `transformImpliedNodeFormatDependentModule`, which decides by the file's implied node format:
  - ESM files go to `esnextAnd2015.ts`;
  - CommonJS files would go to `module.ts`, which is **not in this brief**. See ".cts units" below.

**2. `transformers/esnext.ts`** (800 lines): `using` and `await using` declarations:
- the `__addDisposableResource` / `__disposeResources` helpers D1 ported, and the env object;
- the hoisting of top-level declarations around the `try` block;
- `using` in `for` and `for...of`;
- the export handling at module top level.

**3.** Whatever the transformer chain still needs for these units:
- the order of transformers;
- helper emission and `importHelpers` being off (helpers inline);
- the `"use strict"` prologue rules for modules;
- comments on the synthesized statements.

**.cts units (59 here, 60 in the corpus):** tsc emits CommonJS for them even under the default options, through `module.ts`. Whether that transformer is ported is still open with the author.
- Do not port `module.ts`.
- Route `.cts`/`.cjs` units the way tsc's dispatch does, and leave their `.js` differing if it needs `module.ts`.
- Report how many `.cts` units differ only because of that.

**Scope change (2026-11-03, while D3 ran):** the author decided that `module.ts` is ported. The orchestrator sent the change to the agent: port its CommonJS path as the default options reach it for `.cts`/`.cjs` files, with its inline helpers, and bring the `.cts` units' `.js` to identity as well. This replaces the paragraph above.
