## Goal

**1. `transformers/declarations.ts`** (`transformDeclarations`): the `.d.ts` output of every unit under the default options plus `declaration: true`. This includes:
- statements, members, modifiers and `declare`;
- elision of non-exported and invisible declarations;
- `export {}` and the module-marker rules;
- triple-slash references and `/// <reference types>` as tsc keeps them;
- private class members (`private x;`), parameter properties;
- overloads, accessors, computed property names;
- enums, namespaces (`declare namespace`), `export =`, `export default` of expressions (the `_default` variable);
- `import`/`export` elision and rewriting by visibility (`collectLinkedAliases`, `isEntityNameVisible`);
- comments as tsc keeps them in declarations (`removeComments` false).

**2. The resolver entries D1 left as stubs**, through the node builder (C2), in tsc's declaration-emit modes:
- `createTypeOfDeclaration`, `createReturnTypeOfSignatureDeclaration`, `createTypeOfExpression`, `createLiteralConstValue`;
- `collectLinkedAliases`, `isEntityNameVisible`, `requiresAddingImplicitUndefined`, `getJsxFactoryEntity`;
- also whatever `declarations.ts` asks of the resolver beyond these: `isSymbolAccessible`, `isExpandoFunctionDeclaration`, `getPropertiesOfContainerFunction`, `isOptionalParameter`, `isLateBound`, `getDeclarationStatementsForSourceFile` and others.

**The node builder in declaration mode:**
- reuse of existing type nodes (`tryReuseExistingTypeNode`, `serializeExistingTypeNode`);
- the symbol accessibility tracker (`SymbolTracker`: `trackSymbol`, `reportInaccessibleThisError`, `reportPrivateInBaseOfClassExpression`, `reportCyclicStructureError`, `reportTruncationError` and so on);
- `NodeBuilderFlags` for declaration emit;
- the expression-to-type-node fast path (`expressionToTypeNode.ts`, the syntactic type node builder) as tsc 6.0.3 uses it.

**3. `transformers/declarations/diagnostics.ts`:** the declaration emit diagnostics (`createGetSymbolAccessibilityDiagnosticForNode` and friends), with message, position and order as tsc reports them, so the diagnostics section becomes identical.

**4. JavaScript units** (`allowJs` with `declaration`): declarations from JSDoc, CommonJS `module.exports` / `exports.x` assignments, expando functions, JSDoc `@typedef`/`@callback`, as tsc 6.0.3 emits them.
- Do these after the TypeScript units, as their own step and commit.
- If time runs out, they are the part that moves to a follow-up module.

**Order:** TypeScript units first (the bulk), then the diagnostics, then the JavaScript units.
- Commit each coherent step.
