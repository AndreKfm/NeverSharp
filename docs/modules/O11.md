## The variants

| Variant | Approach | Ideas to evaluate (not prescribed) |
|---|---|---|
| **A: main** | as after O23 | — (measured as the reference) |
| **B: token replay** | tokens scanned while speculating are recorded (kind, positions, flags, value, preceding line break, …) in a per-parse buffer; after a rewind, `NextToken` replays them instead of scanning again, as long as the scanning context matches | invalidate on every re-scan (`ReScanGreaterToken`, template, regular expression, JSX, JSDoc modes) and context change; keep `lookAhead` exact; measure hit rate |
| **C: exact pre-decisions** | where a bounded token-level check can decide exactly what the speculation would decide (e.g. arrow function or parenthesized expression, constructor declaration, async arrow), decide it without the speculative parse; fall back to the real speculation whenever the check is not certain | the check must be provably equivalent for the cases it decides (same tree, same diagnostics); count decided vs fallen-back cases on the tuning corpus |

All variants keep: trees, diagnostics, node positions and flags byte-identical (Gate 1, G1a, ParseNone), thread safety, the NoAlloc contract, the tool contract.
