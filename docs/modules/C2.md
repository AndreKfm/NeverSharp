## Goal

Port the node builder as far as `typeToString`, `signatureToString`, `symbolToString` and `typePredicateToString` need it (`createNodeBuilder` in checker.ts: `typeToTypeNodeHelper`, `signatureToSignatureDeclarationHelper`, `symbolToTypeNode`, `lookupSymbolChain`, `typeReferenceToTypeNode`, `createAnonymousTypeNode`, `createTypeNodeFromObjectType`, mapped/conditional/indexed/template-literal type nodes, tuples, literal shapes, truncation (`NodeBuilderFlags`, `defaultMaximumTruncationLength`), node reuse of existing type annotations (`tryReuseExistingTypeNode`, the `.types` baseline's underline logic), `TypeFormatFlags` → `NodeBuilderFlags`), building synthesized nodes in a Track O node store and printing them with P1's printer with tsc's printer options (`removeComments`, single line where `typeToString` uses `EmitFlags.SingleLine`). Types C2 cannot build yet because C3 has not ported them (generic instantiations, conditional types …) print through the same builder once C3 lands — write the builder for all type kinds from checker.ts, not only for the kinds C1 creates.

Remove C1's minimal printing path where the node builder replaces it.
