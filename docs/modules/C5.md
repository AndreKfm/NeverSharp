## Goal

Port from checker.ts the `checkExpression` family completely, except inference (C6) and narrowing (C7):

- literals and their widening/freshness, template expressions, object literals (`checkObjectLiteral`: spreads, computed names, methods, accessors, `getSpreadType`), array literals (tuples in context, spreads), parenthesized/as/satisfies/non-null expressions, `typeof`/`void`/`delete`/unary and binary operators (arithmetic, comparison, `in`, `instanceof`, logical, nullish, assignment and compound assignment, destructuring assignment), conditional expressions, comma;
- calls and `new` with overload resolution (`resolveCall`, `chooseOverload`, candidate selection, `getSignatureApplicabilityError`, the call diagnostics 2345/2554/2555/2769 with their elaboration via the relater), `super` calls and property access, tagged templates, decorators' call resolution, optional chains, element access with all index kinds;
- function and arrow expressions (`checkFunctionExpressionOrObjectLiteralMethod`, return type inference from bodies — `getReturnTypeFromBody`, `getUnionType` of returns, `void`/`never` rules), class expressions, `this` typing (`checkThisExpression`), `new.target`;
- contextual typing in full (`getContextualType` and its cases, `getApparentTypeOfContextualType`, contextual signatures) — inference of type arguments stays C6, but contextually typed parameters of non-generic signatures belong here;
- destructuring declarations and for-of/for-in iteration types (`getIteratedTypeOrElementType`, iterables/async iterables, 2488/2504 …).

Remove C1's approximate contextual typing and the corresponding parts of the "uncertain" mechanism as C5 makes them exact.
