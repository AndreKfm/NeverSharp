## Goal

The rest of `transformers/ts.ts` under the default options, so that **every unit touched only by the TypeScript transformer has an identical `.js` section**.

Left open by D1:
- **Enums:** `visitEnumDeclaration`, members, auto-numbering, string members, reverse mapping, computed values through the resolver's `getConstantValue`/`getEnumMemberValue`. Also:
  - `const enum` elision (no `preserveConstEnums`, no `isolatedModules` by default);
  - the `var`/`let` declaration of merged and exported enums;
  - `export` of enums inside namespaces.
- **Namespaces (modules):**
  - `visitModuleDeclaration`: the IIFE, nested dotted names, merging with classes, functions and enums (`LexicalModuleMergesWithClass`);
  - elision of non-instantiated namespaces (`isInstantiatedModule`, `shouldEmitModuleDeclaration`);
  - `declare` and ambient modules.
  - **Namespace exports:** substitution of exported names (`substituteExpressionIdentifier`, `getNamespaceMemberName`), exported variables as assignments, exported functions and classes. D1 throws here.
- **Import-equals:**
  - `import x = a.b` with entity names: `isReferencedAliasDeclaration`, `isTopLevelValueImportEqualsWithEntityName`, export inside namespaces;
  - `import x = require(...)`: keep what `ts.ts` does. Its module-kind rewrite belongs to D3.
- **Unique names for modules and enums:** `getGeneratedNameForNode` / `makeUniqueName` with the binder's locals, which D1 throws on.
- **Printer:** the parenthesizer rules for substituted nodes (`emitExpression` with `parenthesizerRule` on substitutes), needed by the namespace export substitution.
- **Whatever else of `ts.ts` the TypeScript-only units reach:**
  - `export =` and `export default` paths that stay in `ts.ts`;
  - `this` in namespaces;
  - decorated parameter properties only if no decorator transformer is involved;
  - the comments and source positions tsc puts on synthesized enum and namespace nodes (`setCommentRange`, `setTextRange`, the emit flags `NoComments`, `NoNestedComments`, `NoLeadingComments` and so on).

**Out of scope:**
- the ES module transformer and `esnext.ts` (D3);
- decorators and class fields (D4);
- `.d.ts` and declaration diagnostics (D5).

Units touched by those transformers stay differing. Do not port parts of those transformers to make them match.

The 60 `.cts` units (CommonJS output) are still open with the author. Do not work on them.

**Target:**
- All 2,589 TypeScript-only units with an identical `.js` section. Report the ones that are not, each with its cause.
- No regression in any section: the 41,490 identical `.js` sections and the 301 no-transformer units stay identical.
- The printer gate stays identical in both modes. Gate C stays identical after any checker change.
