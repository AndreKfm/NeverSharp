# M2: Scanner (Track F) — brief for porting attempts

Module M2 of [phase1-plan.md](../phase1-plan.md) §4. Every attempt receives exactly this brief and the inputs it names (pre-registration §5.2). Written by the orchestrator before any attempt started.

## Scope

The 67 units listed in [M2-units.md](M2-units.md) (generated by `harness/port/modules.mjs --module M2`): every unit of `scanner.ts` that the parser reaches — `createScanner` (3,011 lines, including the regular-expression validator and JSDoc scanning), trivia and comment ranges, line starts, the keyword and token tables, the Unicode identifier tables — plus `parsePseudoBigInt`, `forEachEntry`, `getNameOfScriptTarget` (utilities.ts), `targetOptionDeclaration` (commandLineParser.ts, only what `getNameOfScriptTarget` needs) and `LanguageFeatureMinimumTarget` (types.ts).

Module M1 is merged and is the base: `src/NeverSharp.Faithful/Core/` (`Core`, `TsPath`, `Debug`, `Utilities`, `UtilitiesPublic`, `FactoryUtilitiesPublic`, `TextRange`, `TextSpan`). Use it; do not change it. Enums and diagnostic messages are generated (`src/Generated/`); `Diagnostics.<Name>` are TypeScript's messages.

All of the listed units are ported. Regular expressions in the source (`shebangTriviaRegex`, `commentDirectiveRegExSingleLine`/`MultiLine`, `jsDocSeeOrLink`, and any inside `createScanner`) are banned in Track F and become hand-written matching code with exactly the regex's semantics.

## C# API (fixed; the gate, the dump tool and the benchmark call it)

- Namespace `NeverSharp.Faithful`, everything `internal`. Names: TypeScript's name in PascalCase; types as in [M1.md](M1.md) (positions `int`, `T | undefined` nullable, arrays `List<T>`/`IReadOnlyList<T>`).
- `scanner.ts` → `internal sealed partial class Scanner`. Its **instances** are the objects `createScanner` returns (TypeScript's `interface Scanner`; the closure state becomes fields, the inner functions methods). The file-level functions of `scanner.ts` are **static** members of the same class (`Scanner.CreateScanner`, `Scanner.SkipTrivia`, `Scanner.TokenToString`, …). `utilities.ts` units go to `Utilities`, `commandLineParser.ts` to `CommandLineParser`, `types.ts` to `Types`.
- `internal delegate void ErrorCallback(DiagnosticMessage message, int length, object? arg0);` (scanner.ts `ErrorCallback`).
- Called by the tools and tests:
  - `static Scanner CreateScanner(ScriptTarget languageVersion, bool skipTrivia, LanguageVariant languageVariant = LanguageVariant.Standard, string? textInitial = null, ErrorCallback? onError = null, int? start = null, int? length = null)`
  - instance: `SyntaxKind Scan()`, `int GetTokenFullStart()`, `int GetTokenStart()`, `int GetTokenEnd()`, `TokenFlags GetTokenFlags()`, `string GetTokenValue()`, `void SetText(string? newText, int? start = null, int? length = null)`, `void SetOnError(ErrorCallback? errorCallback)`, `void SetLanguageVariant(LanguageVariant variant)`; the rest of TypeScript's `Scanner` interface likewise (the parser needs it in M4).
  - static: `List<CommentRange>? GetLeadingCommentRanges(string text, int pos)`, `GetTrailingCommentRanges(string text, int pos)`, `int SkipTrivia(string text, int pos, bool stopAfterLineBreak = false, bool stopAtComments = false, bool inJSDoc = false)`, `List<int> ComputeLineStarts(string text)`, `string? GetShebang(string text)`, `LineAndCharacter ComputeLineAndCharacterOfPosition(IReadOnlyList<int> lineStarts, int position)`, `bool IsIdentifierText(string name, ScriptTarget languageVersion, LanguageVariant identifierVariant = LanguageVariant.Standard)`, `string? TokenToString(SyntaxKind t)`, `SyntaxKind? StringToToken(string s)`, `string Utf16EncodeAsString(int codePoint)`.
  - `Utilities.ParsePseudoBigInt(string stringValue)` → `string`; `Utilities.GetNameOfScriptTarget(ScriptTarget scriptTarget)` → `string?`.
  - Types (types.ts interfaces, defined in `Scanner/`): `CommentRange` with `Pos`, `End`, `Kind` (`SyntaxKind`), `HasTrailingNewLine` (`bool`), implementing M1's `TextRange`; `LineAndCharacter` with `Line`, `Character`.

## Gate (run it, iterate until it passes)

```
<main>/.tools/node-24.21.0/node.exe harness/port/gate.mjs --module M2 --main D:/Private/Source/Andre/projects/NeverSharp
```

from the attempt's checkout. It runs:

1. Gate 2: Release build of `src/NeverSharp.Faithful` with the Track F analyzers (warnings are errors), header check.
2. Unit tests (`tests/NeverSharp.Faithful.Tests`): M1's tests (regression) and M2's: about 1.4 million calls of the exported scanner helpers compared with tsc 6.0.3 (`harness/port/vectors-m2.mjs`: comment ranges, `skipTrivia` and line/character at every token position of 502 corpus units, `isIdentifierText`, token strings, keywords, pseudo-bigints).
3. **G1a**: `tools/NeverSharp.Dump tokens` scans all 50,177 units of the equivalence corpus (format: [ast-dump-format.md](../ast-dump-format.md) §8; 22,809,973 tokens) and `harness/astdump/compare-tokens.mjs` compares each unit's token stream with tsc 6.0.3's **byte for byte**. It prints the first differing line of the first 15 differing units. The dump writer was checked by replaying tsc's own dumps through it (50,177 of 50,177 identical), so a difference is the scanner's.

Analyzer findings are fixed in the code, never suppressed, except with a `#pragma warning disable` that names a reason tied to faithfulness; each suppression is listed in the report. An attempt ends when the gate passes or after 40 gate runs.

Useful for iterating: `harness/astdump/compare-tokens.mjs --show 50`, and the unit texts in `<main>/artifacts/equivalence/units/<id>.txt` with tsc's dumps in `<main>/artifacts/equivalence/dumps/ts-tokens/<id>.txt` (read-only).

## Independence

Attempts do not see each other: do not read other worktrees, branches or attempt reports, and not the `attempts/*` branches. Port from the inputs above.

## Report (the attempt's last message)

1. Model identifier.
2. Gate result (the JSON summary line of the last gate run) and the number of gate runs.
3. Units not ported (none expected) with reasons; `#pragma` suppressions with reasons.
4. Deviations from the TypeScript source that C# forced, each with file and line.
5. The commit hash of the attempt on its branch (`git commit -s`).

## Ranking (orchestrator, fixed before the attempts)

Survivors of the gate are ranked (pre-registration §5.2) by the median wall-clock of the M2 workload, then by bytes allocated: `bench/NeverSharp.Benchmarks`, `M2.ScanTuningCorpus` — one scanner created as the parser creates it (`createScanner(Latest, skipTrivia: true)`), and for each of the 24,511 files of the tuning corpus (read with sys.ts semantics, beforehand) `SetText`, `SetOnError`, `SetLanguageVariant` (JSX for `.tsx`/`.jsx`), then `Scan()` until `EndOfFileToken`. BenchmarkDotNet, NativeAOT, 3 warmup + 20 measured iterations, MemoryDiagnoser, attempts measured one after another on an otherwise idle machine. The winner is merged; all attempts, gate logs and numbers are recorded in [phase1-progress.md](../phase1-progress.md).
