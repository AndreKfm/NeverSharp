## Goal

Port from checker.ts (structure may follow typescript-go's `internal/checker`, `mapper.go`):

- type mappers (`TypeMapper` kinds: simple, array, deferred, function, composite, merged), `instantiateType` / `instantiateTypeWorker` with tsc's depth and count limits and the "excessively deep" diagnostics, `instantiateSignature`, `instantiateSymbol`, `getObjectTypeInstantiation` and its caching (`instantiations` keyed by type-argument ids), generic type references (`createTypeReference`, `getTypeArguments`, resolved base types of generic classes/interfaces, `this` types);
- tuple types (`createTupleType`, labeled/optional/rest/variadic elements, normalization), array and readonly array types;
- indexed access types (`getIndexedAccessType`, `getPropertyTypeForIndexType`), `keyof` (`getIndexType`), mapped types (`resolveMappedTypeMembers`, homomorphic mapping, modifiers), conditional types (`getConditionalType`, distributive instantiation, `infer` type parameters — the inference itself is C6, use the structure and leave the inference call stubbed if needed), template literal types and string mapping types (`Uppercase` …), substitution types, `unique symbol` types;
- generic signatures, type parameter constraints and defaults (`getConstraintOfTypeParameter`, `getDefaultFromTypeParameter`), `getApparentType`, `getReducedType`, `getBaseConstraintOfType`;
- type alias instantiation (`getTypeFromTypeAliasReference`), `getTypeFromTypeNode` for the remaining generic type node kinds.

Type ids must be assigned in tsc's creation order (unions and intersections order by type id).
