# P1: printer (for type printing) — brief

Module P1 of Phase 3 ([phase3-plan.md](../phase3-plan.md)), runs in parallel with C0 because it does not depend on the checker's data layout: `typeToString` / `symbolToString` build type nodes with the node builder and print them with TypeScript's printer (`createPrinter` in `src/compiler/emitter.ts`, lines 1211 ff., about 5,000 lines with its helpers; typescript-go's `internal/printer`). Every diagnostic that names a type, and the whole types section of Gate C, depends on it. Track O only. Written by the orchestrator. Standing rules of [README.md](README.md); run only the tests and gates your change affects.

## Goal

1. Port the printer into Track O (`src/NeverSharp.Optimized/Printer/`): `createPrinter(printerOptions, handlers)`, `printNode(hint, node, sourceFile)`, `printFile`, the `emit*` functions for every node kind, the text writer (`createTextWriter`), escaping of string/template literals and identifiers, `getLiteralText`/`getTextOfNode` behaviour, parenthesization as the printer applies it, list formats (`ListFormat`), `EmitFlags` handling needed for synthesized nodes (single line, no indentation, etc.), and comments **only** as far as `removeComments: true` needs (no source maps, no comment emission, no transformers, no `emitResolver`).
2. **Printer gate (P):** an oracle `harness/astdump/dump-ts-printer.mjs` that parses every equivalence unit with tsc 6.0.3 (as `dump-ts.mjs` does, JSDoc mode ParseForTypeErrors) and writes `ts.createPrinter({ removeComments: true, newLine: LineFeed }).printFile(sourceFile)` per unit; the C# side prints Track O's parse of the same unit with the ported printer (`tools/NeverSharp.Dump.Optimized --printer`); a compare (byte identity per unit, summary counts). Add `--phase printer` to `harness/port/gate.mjs` (build, headers, cached oracle, C# dumps, compare only).
3. Target: printer gate byte-identical on all 50,177 units. Printing parsed trees exercises the same `emit*` paths the node builder's synthesized type nodes use later, plus statements and expressions; where a difference comes only from parsed-source specifics the type printer never needs (e.g. emitting original source text of literals), still match tsc.
